# tragent CLI releases

This repository hosts the release binaries for the **tragent** command-line
tool. The source lives in a private repository; nothing here is built from
this repo.

Install with npm:

```bash
npx @tragent/cli --version
```

Or download an archive for your platform from
[Releases](https://github.com/tragent-io/cli/releases) and check it against
`checksums.txt`.

tragent tests whether AI shopping agents can buy from your store:
[tragent.io](https://tragent.io).
